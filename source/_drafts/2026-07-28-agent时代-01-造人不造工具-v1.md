## 一、菜香飘过来了

2026年7月，一个普通的周二。

Anthropic的估值在一个月内从3800亿美元飙到9650亿美元，第一次超过了OpenAI。不是因为它的模型比GPT-5强——是因为它造了一个叫Claude Code的东西。一个能自己写代码、自己跑测试、自己修bug的Agent。

投资人不是在买模型。是在买"未来的程序员"。

同一周，Cursor——那个AI编程编辑器——估值到了500亿美元，年收入20亿。它做的事情看起来很简单：让AI帮你写代码。但它不是工具。它记得你上次写了什么，知道你的项目结构，能在你打字的时候预测你下一步要干什么。

DeepSeek融了74亿美元。月之暗面200亿估值。Hark——一个你可能还没听过的名字——A轮7亿美元，估值60亿。

钱在往一个方向涌。那个方向叫**Agent**。

## 二、什么是Agent？一句话说清楚

先别急着看那些花里胡哨的定义。

Agent = LLM + 循环 + 工具。

就这样。没有魔法，只有工程。

**LLM**是大脑——能理解语言、能推理、能生成。**循环**是心跳——不是回答一个问题就结束，而是一轮一轮地思考、行动、观察、再思考。**工具**是手脚——能搜索网页、能调用API、能写文件、能发邮件。

但这个等式有一个隐含的前提：**循环**。

没有循环的LLM是工具——你问它答，答完就忘。有循环的LLM是Agent——它能自己决定下一步做什么，能从结果中学习，能在你不在的时候继续工作。

2024年之前的AI是"你问我答"。2026年的Agent是"你说个目标，我自己干"。

这个区别，看起来很小。但它改变了一切。

## 四、六个你以为知道但其实不知道的事

### 1. Agent不是更聪明的ChatGPT

ChatGPT是工具。你问它答，答完就忘。它是瑞士军刀——什么都能做一点，但做完就放下。

Agent是**另一个自己**。它有记忆、有偏好、有技能、能自主行动。你不会"使用"它，你会"和它共处"。

区别在哪？在于**循环**。ChatGPT回答完一个问题就结束了。Agent回答完一个问题，会问自己："这个回答对吗？需要补充什么？下一步该做什么？"它在不断地自我对话。

### 2. 95%的Agent活不过一周

这是2025年最残酷的数据。AutoGPT在2023年证明了"造Agent不难"，但95%的失败率证明了"造能稳定工作的Agent才难"。

失败的原因不是模型不够聪明。是工程不够扎实：状态管理崩溃、工具调用格式错误、推理到一半跑偏、token消耗失控。这些在demo里不会出现的问题，在生产环境里每天都在发生。

### 3. Benchmark漏掉了82%的真实失败

"The Capability Frontier"这篇论文揭示了一个尴尬的事实：当前的benchmark漏掉了82%的Agent真实失败模式。

也就是说，我们以为Agent很能干，是因为我们的考试题太简单了。真正工作中遇到的那些"忘了之前说过的话""工具调用格式错了""推理到一半跑偏了"——这些在benchmark里几乎不出现。

像一个学生每次模拟考都满分，一到高考就崩。

### 4. 同一个工具，写法不同准确率差30%

Tool Calling研究发现：同一个工具，因为Schema（接口描述）写法不同，准确率差异可以达到30%。

工具本身不变，你描述工具的方式决定了Agent能不能用好它。

这像什么？像你给一个新员工一本操作手册。手册写得好，他上手就快；手册写得烂，他对着机器发呆。工具调用的本质不是技术，是**沟通**。

### 5. Harness比模型更重要

Self-Harness论文（NeurIPS 2026）提出了一个颠覆性观点：**Agent的能力上限不由模型决定，由Harness决定**。

Harness是Agent的工程骨架——Prompt怎么写、记忆怎么管、工具怎么编排、子Agent怎么协调。模型是大脑，Harness是身体。大脑再聪明，身体不协调也做不好事。

这意味着：Scaling Law正在从"模型更大"转向"Harness更好"。

### 6. 没有单一记忆架构全面碾压

"Are We Ready For An Agent-Native Memory System?"这篇论文评估了12个记忆系统、5个基准、11个数据集。

结论：**无单一架构在所有场景占优。**

向量存储适合简单事实，知识图谱适合时序推理，仿生认知网络适合长期推理，有状态OS适合透明管理。每种架构各有擅长的领域。

翻译成人话就是：记忆不是一个技术问题，是一个**选择问题**。你选择记住什么、忘掉什么、什么时候巩固、什么时候遗忘——这些选择本身定义了Agent是谁。

## 五、造人不造工具

这篇文章的标题叫"造人不造工具"。这不是修辞，是立场。

2023年的AI是工具。你用ChatGPT写邮件、用Midjourney画图、用GitHub Copilot补全代码。它们是高级的螺丝刀、好用的画笔、聪明的自动补全。

2026年的Agent不是工具。它记得你昨天说了什么，知道你的项目结构，能在你不在的时候自己跑测试，能在你犯错的时候提醒你——不是因为你设置了提醒，而是因为它**理解**你在做什么。

这个区别，就像计算器和会计师的区别。计算器是工具——你给它数字，它给你结果。会计师是专业人士——他理解你的业务，能主动发现问题，能提出建议，能在你不在的时候独立工作。

Agent就是AI世界的"专业人士"。

但"专业人士"还不够。真正的突破是：Agent能**自己变得更强**。

Self-Harness让Agent能改进自己的运行环境。Gödel Agent让Agent能递归地扩大能力边界。Agent-Native Memory让Agent能从经验中学习。

这不是工具在变强。这是**人在被造出来**。
