一个是图纸，一个是房子。 你到底要哪个？

一、你混淆了两件事

上一章我们说了，Agent = LLM + 记忆 + 循环 + 工具。听起来简单得像一加一。

但当你真的坐下来想"我要一个Agent"的时候，你会发现自己面对的第一个问题不是"模型选哪个"，而是——你是要造一个Agent，还是要用一个Agent？

这两个问题的答案完全不同。

造Agent，你需要的是框架——LangGraph、CrewAI、MetaGPT、OpenAI Agents SDK。它们是工具箱、是蓝图、是乐高积木。你用它们来构建你自己的Agent。

用Agent，你需要的是智能体产品——Claude Code、Cursor、Codex、OpenClaw、OpenHuman、Hermes Agent。它们是已经造好的房子、已经训练好的猎犬、已经上线的员工。你直接使用它们。

框架是给开发者的。智能体是给所有人的。

把它们放在同一张桌子上比较，就像比较"锤子"和"房子"——它们不是同一个维度的东西。

二、框架：给开发者造Agent的工具箱

框架的世界是开发者的世界。你用代码定义Agent的行为，用配置决定Agent的能力，用部署让Agent活起来。

框架 核心隐喻 适合谁 代价
LangGraph 米其林后厨 复杂工作流团队 学习曲线陡峭
CrewAI KTV包厢 快速原型/团队协作 无持久记忆
MetaGPT 软件工厂流水线 软件工程多Agent 手工SOP成本高
OpenAI SDK 极简积木 快速试水 无状态管理
Google ADK 企业平台 Google Cloud用户 锁定风险
AutoGen 退场的先驱 已有系统 维护模式，不推荐新项目
NVIDIA DeepAgents 深水潜艇 复杂长周期任务 需NVIDIA生态

NVIDIA DeepAgents值得单独说——它是英伟达对Agent架构的官方定义：Agent = 规划 + 持久记忆 + 工具执行 + 可复用技能 + 子Agent委托。这不是一个具体的框架，而是一套架构规范，告诉开发者"Agent应该长什么样"。它的生态位很特殊：不是给你造Agent的工具箱，而是告诉你造Agent的蓝图。

但框架是Agent的子宫。 没有框架，智能体产品无从诞生。Claude Code底层跑的是LangChain的链条；OpenClaw的工具调用遵循MCP协议——而MCP最早就是框架社区推动的。框架是基础设施，智能体是上层建筑。你可以不住在工地上，但你住的房子一定是从工地长出来的。

框架的价值在于灵活性——你可以造任何你想要的Agent。代价在于工程量——你得自己造。

2026年的数据显示，89%的Agent试点项目未能达到规模化生产（Deloitte 2026 Tech Trends）。其中很大一部分不是因为模型不行，而是因为框架选错了——用LangGraph搭了个只需要CrewAI的小项目，学习曲线吃掉了所有时间；或者用OpenAI SDK搭了个需要持久化的企业系统，发现连检查点都没有。

但框架不是这篇文章的重点。重点是第二类：已经活着的Agent。

三、智能体：已经住人的房子

Claude Code：编程Agent的王者

Claude Code是Anthropic造的编程Agent。不是框架，不是SDK，是一个你装上就能用的工具。

安装：npm install -g @anthropic-ai/claude-code，然后在项目目录运行claude即可。操作：进入交互界面后，直接用自然语言描述任务——"帮我修这个bug""重构这个模块""写测试"。/goal模式可以给它一个大目标，它自己拆解执行。

核心能力： - /goal自主模式——给它一个目标，它自己规划、自己执行、自己测试、自己修bug - Sandbox安全执行——在隔离环境中运行，不会搞坏你的系统 - 代码库理解——它不只看当前文件，能理解整个项目的结构 - Shell命令执行——能自己跑测试、装依赖、看日志 - 不只是编程——2026年的CC已经能做代码审查、架构分析、文档生成、技术调研，甚至帮你写周报

为什么它是王者？ 因为它证明了一件事：Agent可以端到端地完成真实软件工程任务。 不是帮你补全代码，不是帮你写函数，是帮你从需求到交付。

Anthropic内部数据：Claude Code让开发者的生产力提升了40%以上。但更重要的是它的自主性——你给它一个issue，它能自己读代码、找bug、修代码、跑测试、提交PR。你在旁边喝咖啡就行。

避坑指南：大项目首次加载可能很慢（需要索引整个代码库）；token消耗惊人，复杂任务一次可能花几美元；Sandbox有时候会和本地环境不一致，部署前一定要在本地验证。

局限：主要面向终端用户，IDE集成不如Cursor丝滑。它是专才型通才——编程场景无敌，其他场景有限。

Cursor：IDE里的Agent

Cursor是另一个编程Agent，但走了一条不同的路——它不是终端里的工具，而是IDE里的伙伴。

安装：下载cursor.com，直接安装（VSCode fork，无缝迁移）。操作：Cmd+K打开Agent模式，自然语言描述任务；Tab键触发智能补全；Ctrl+L打开Chat面板做复杂对话。

核心能力： - Tab补全+Agent模式无缝切换——打字时它预测你要写什么，复杂任务时它自己规划 - 项目级理解——知道你的代码结构、依赖关系、编码风格 - 多文件编辑——能同时修改多个文件，保持一致性 - 上下文窗口——能"看到"你的整个项目，不只是当前文件

为什么它有500亿估值？ 因为它解决了开发者最痛的问题：上下文切换。 你不用在IDE和终端之间跳来跳去，不用在代码和文档之间复制粘贴。Cursor在你工作的环境里工作。

与Claude Code的区别：Cursor更像"增强版IDE"——你在里面写代码，它帮你补全、重构、调试。Claude Code更像"自主程序员"——你给它任务，它自己干完。

Codex：OpenAI的Agent野心

Codex是OpenAI的编程Agent，2026年4月发布了goals支持。但更戏剧性的是——2026年7月，Codex已经合并入ChatGPT桌面应用。OpenAI不再单独卖编程Agent，而是把Agent能力塞进了ChatGPT这个超级App里。

安装/使用：不再需要单独安装。打开ChatGPT桌面版，在对话框里直接说"帮我写一个脚本"或"分析这个代码库"，ChatGPT会自动调用Codex能力。云端执行——不占本地资源。

核心能力： - 云端执行——不占本地资源，能在大机器上跑 - Goals支持——给它目标，它自己规划执行 - 大模型驱动——背后是GPT-5.6（三版本：Sol旗舰/Terra平衡/Luna最快） - ChatGPT Work——长时间运行的Agent，能跨应用收集信息、创建文档/幻灯片/网站，自主执行数小时

为什么这很重要？ 因为OpenAI正在走一条和Anthropic完全不同的路——不是造一个独立的编程工具，而是把Agent融入对话框，做一个超级App。你不需要学习新工具，在你已经习惯的ChatGPT里就能用Agent。

避坑：云端执行意味着代码和数据会上传到OpenAI服务器；隐私敏感项目慎用；Goals功能还在早期，复杂目标有时候会跑偏。

与Claude Code的区别：Codex更偏"云端作业+对话式"，Claude Code更偏"本地终端+自主式"。Codex适合需要大量计算的任务，Claude Code适合需要和本地环境紧密交互的任务。

OpenClaw：全民Agent的引爆点

OpenClaw是2026年Q1最火的Agent。不是因为它技术最强，而是因为它最平民。

核心能力： - 本地运行——数据完全在你自己机器上，隐私有保障 - 多平台接入——WhatsApp、Telegram、Discord、Slack、微信……你用什么聊天，它就出现在哪里 - Computer Use——能控制你的电脑，打开浏览器、操作文件、执行命令 - 开源——代码完全公开，社区驱动

为什么Mac Mini卖到断货？ 因为OpenClaw让普通人第一次感受到"AI Agent在我身边"。不是在浏览器里聊天，不是在IDE里写代码，而是在我的手机上、在我的电脑上、在我的生活里。

Fast Company把OpenClaw的创始人列入了2026年AI 20。截至2026年7月，OpenClaw在GitHub上已有38.4万+星标，超越Linux和React，登顶GitHub历史第一。50万+系统在运行——但CNCERT也发出了安全预警：全球公网暴露实例超41万个，国内约23万个"裸奔"。

安装：npx openclaw setup（5分钟上手）。避坑：不要把端口暴露在公网，一定要用HTTPS+认证；Computer Use权限不要给太大；定期更新，安全漏洞修复很快。

局限：功能不如Claude Code专业，稳定性不如商业产品。安全意识需要用户自己把关。但它的价值不在于"最好"，而在于"最亲"。

OpenHuman：有记忆的Agent

OpenHuman是TinyHumans AI造的个人AI超级智能体。33K+ GitHub Stars，Rust编写，本地优先。

安装：GitHub仓库提供一键安装脚本，支持macOS/Linux/Windows。操作：配置好API密钥后，通过CLI或GUI与Agent交互。核心是设置你的"记忆偏好"——告诉它你希望它记住什么、忘掉什么。

核心能力： - Memory Tree——本地优先的记忆系统，跨session记住你的一切 - Agent编排引擎——管理多个Agent协同工作（支持连接Claude Code、Codex、OpenClaw、Hermes等） - 深度研究——能搜索、分析、综合信息 - 本地运行——数据不离开你的机器 - Agent-to-Agent通信——基于Signal协议端到端加密，可以连接多个Agent形成网络

避坑：Rust编写的，编译安装需要一定技术能力；Memory Tree在大规模数据下性能待优化；生态还在早期，插件不多。

与OpenClaw的区别：OpenClaw更偏"执行"——帮你操作电脑、管理消息。OpenHuman更偏"记忆"——帮你记住事情、理解你、成为你的数字分身。

与Hermes Agent的区别：两者都是"有记忆的Agent"，但OpenHuman更偏"个人助手"（帮你记事、帮你研究），Hermes更偏"自主Agent"（自己干活、自己学习、自己进化）。

Manus：被Meta收编的行动引擎

Manus是2026年最戏剧性的Agent故事——一个中国团队造的自主Agent平台，被Meta以20亿美元收购。

核心能力： - Wide Research——深度研究，能搜索、分析、综合海量信息 - Browser Operator——浏览器自动化，能操控网页完成任务 - API/Mail/Slack集成——能发邮件、调API、管消息 - 设计工具——能操作Figma等设计工具 - Meta集成——被收购后深度嵌入Meta生态

为什么它被Meta看中？ 因为Manus做到了大多数Agent做不到的事：端到端执行真实世界的复杂任务。 不是聊天，不是补全，是"帮我调研竞品→写分析报告→发邮件给团队"这种跨工具、跨平台的完整工作流。

被收购的意义：Meta不买技术，买的是用户行为数据。Manus的用户在用Agent做什么、怎么做、哪里卡住了——这些数据对Meta训练下一代Agent价值连城。

局限：闭源、商业化、数据归Meta。你用Manus，你的行为数据就是Meta的。

Hermes Agent：自主Agent的终极形态

Hermes Agent是Nous Research造的开源Agent。1.3M行Python，20+平台网关，8种记忆插件，技能自生成。

核心能力： - 完全自主——给它一个目标，它自己规划、自己执行、自己学习 - 跨平台——Telegram、Discord、Slack、WhatsApp、Signal、Email、CLI、Web UI……20+平台 - 持久记忆——8种记忆插件（session/jiak/RECALL/JCoT/Δ胶囊/章鱼搜索），跨session记住一切 - 技能自生成——从经验中自动创建技能，使用中自动改进 - Cron调度——自然语言设定定时任务，无监督运行 - 子Agent——能spawn独立的子Agent，隔离终端+RPC，零上下文成本

与其他Agent的根本差异：

维度 Hermes Agent 其他Agent
定位 通用自主Agent 编程/助手/特定场景
记忆 8种插件，跨session 多数有限或无
技能 从经验自动生成 固定工具集
平台 20+消息平台 1-2个平台
调度 内置Cron 需外部调度
开源 MIT License 多数闭源

为什么说它是"自主Agent的终极形态"？ 因为它做到了其他Agent都做不到的事：它不只是执行任务，它在进化。 它从经验中学习，从错误中改进，从对话中生成新技能。今天的Hermes和三个月前的Hermes不是同一个Agent。

局限：配置复杂度高，面向个人/小团队使用，非企业编排场景。它是"数字伴侣"，不是"企业工具"。

四、两类桌子的真相

框架和智能体，哪个更好？

这个问题本身就问错了。它们不是竞争关系，是生态链的上下游。

框架是Agent的子宫和训练场。没有LangGraph/CrewAI这些框架推动MCP协议、Function Calling标准、Agent Loop范式，就没有Claude Code的底层能力，没有OpenClaw的工具调用，没有Hermes的记忆插件。框架社区是Agent世界的基础科学——它们定义了"Agent是什么"，智能体产品只是这些定义的工程实现。

但框架永远无法替代智能体。因为普通用户不会写Python，不会配LangGraph的状态图，不会调CrewAI的Agent角色定义。他们需要的是：装上就能用的东西。

所以两类桌子的真相是：

你要做什么 选谁 为什么
造一个定制化的Agent 框架（LangGraph/CrewAI） 你有工程能力，需要完全控制
编程，要一个自主程序员 Claude Code 端到端软件工程，从需求到交付
编程，要IDE集成 Cursor 在你写代码的环境里帮你写
要一个生活助手 OpenClaw/OpenHuman 5分钟上手，住在你的聊天工具里
要跨工具复杂任务执行 Manus 调研→分析→报告→邮件，全链路
要一个全能自主Agent Hermes Agent 记忆+技能自生成+Cron调度
什么都不懂，想试试 OpenClaw（5分钟上手） 开源、免费、社区活跃
造Agent但不想从零开始 NVIDIA DeepAgents 架构规范+参考实现

渗透正在发生。 框架在往智能体的方向走——LangGraph发布了LangGraph Platform，让你一键部署Agent。智能体在往框架的方向走——Hermes Agent开放了skill系统，让你像搭积木一样扩展它的能力。两者的边界在模糊，就像手机和相机的边界在模糊一样——最终，它们会融合成一个东西。

五、Agent的军备竞赛

2026年的Agent战场，本质上是一场自主性的军备竞赛。

谁能工作更久？Claude Code能在无人值守的情况下运行数小时。Hermes Agent能通过Cron 24/7无监督运行。

谁能记住更多？OpenHuman的Memory Tree、Hermes的8种记忆插件、Oracle的93.8%准确率记忆系统。

谁能做更多事？OpenClaw能控制你的电脑，Hermes能接入20+平台，Claude Code能端到端完成软件工程，Manus能跨工具执行完整工作流（调研→分析→写报告→发邮件）。

谁能自己变强？Hermes从经验中生成技能，Self-Harness让Agent改进自己的运行环境，Gödel Agent让Agent递归扩大能力边界。

这场军备竞赛的终局是什么？可能是：Agent不再是工具，而是伙伴。 你不会"使用"它，你会"和它共处"。

但在那一天到来之前，Agent还需要解决一个根本问题：记忆。
